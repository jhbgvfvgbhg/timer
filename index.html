🐈 SECRET SETTINGS

Type "cat" anywhere on the timer to open this menu.

⏱ Time

Controls where the timer starts and what time it tries to move toward.
When enabled, the timer starts at your current system time (HH:MM format). When disabled, uses the "Starting time" field below.
The time displayed when you press Restart (if "Start at system time" is disabled). For example, 18:00 starts the timer at eighteen minutes.
Computer time makes the target follow your real clock. Custom time gives the timer a fixed target instead.
The target used when Target Mode is set to Custom time. Example: 20:00 makes the timer tend toward twenty minutes.

↔ Direction

These settings determine how strongly the timer wants to move toward its target.
When the timer is away from the target, this is the chance that it moves back toward it. Higher values make the timer more obedient.
Controls how often the timer ignores the target and moves in the opposite direction. Higher values make its behavior more chaotic. These two always total 100%.

⚡ Movement Speed

The timer always changes by seconds, but these settings control how quickly those changes happen. 1000 ms means one second between movements.
The standard movement speed. 1000 ms means the timer changes once every second.
How quickly the timer moves during a fast section. 500 ms means two timer seconds appear every real second.
An extremely fast movement speed. 250 ms means four timer seconds appear every real second.
A slow movement speed. 3000 ms means one timer second appears every three real seconds.

🎲 Speed Chances

Every 5-10 seconds, the timer chooses a new movement speed. These percentages control how likely each speed is to be selected.
Chance of selecting the normal movement speed.
Chance of selecting the fast movement speed.
Chance of selecting the very fast movement speed.
Chance of selecting the slow movement speed.
Tip: the four speed chances should add up to roughly 100%.

⏲ Mode Timing

Controls how long the timer waits before changing its speed or direction mode. A random interval between the minimum and maximum is chosen each time.
Shortest time (in milliseconds) the timer waits before changing modes. 5000 ms means at least 5 seconds. This is the lower bound.
Longest time (in milliseconds) the timer waits before changing modes. 10000 ms means at most 10 seconds. This is the upper bound.

🦘 Jumps

Jumps allow the timer to occasionally skip several seconds at once instead of moving by exactly one second.
The chance that any individual movement will become a jump instead of a normal one-second movement.
The smallest number of seconds a jump can move the timer.
The largest number of seconds a jump can move the timer.

🧮 Smart Speed

Math-based speed modifiers that change based on how far the timer is from its target. These are super chaotic!
When enabled, the timer speeds up the closer it gets to the target, and slows down when it moves away. This creates a pulling effect toward the target.
When enabled, the timer is always at normal speed, but slows down dramatically when moving away from the target. Creates a "resistance" effect.
How much slower the timer becomes when moving away (only used when "Slow only when moving away" is on).
When enabled, the timer picks a new random speed for every single movement instead of waiting 5-10 seconds. Makes it even more chaotic!

🌀 Chaos Modes

Totally optional nonsense that makes the target and the movement feel more alive, weird, and unstable.
Makes the target wobble and the speed oscillate sinusoidally. Pretty trippy!
Makes the target orbit around a point instead of staying still. Combines chaotically with other modes!
How far and how fast the target orbits. Higher values make wider, faster orbits.
A universal "chaos" dial. It widens the chance and size of jumps, and makes the timer's direction bias more erratic. 1 = normal, higher = more chaotic. Your speed settings are used exactly as entered.
